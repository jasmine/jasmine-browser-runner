# jasmine-browser-runner 5.0.0 Release Notes

## Summary

This is a major release that includes breaking changes. It updates jasmine-core
to 7.0.0. In addition to the list of breaking changes below, be sure to read the
[release notes for `jasmine-core` 7.0.0](https://github.com/jasmine/jasmine/blob/main/release_notes/7.0.0.md).
You may also find the
[upgrade guide](https://jasmine.github.io/upgrade-guides/7.0) helpful.

## Changes to supported environments

* Added Node 26.
* Dropped Safari 16 and 17.
* Added Firefox 140 (current ESR).
* Dropped Firefox 102, 115, and 128 (old ESRs).

## Breaking changes

* The `color` and `alwaysListPendingSpecs` config options are no longer 
  supported. Set
  `defaultReporter: { alwaysListPendingSpecs: ..., color: ... }` instead. †
* Removed Express dependency. This considerably reduces jasmine-browser-runner's
  dependency footprint, at the cost of breaking compatibility with existing
  user-provided middleware. See the [API reference](https://jasmine.github.io/api/browser-runner/5.0/Configuration.html#middleware)
  or the [examples in the jasmine-browser-runner test suite](https://github.com/jasmine/jasmine-browser-runner/blob/5.0/spec/fixtures/middlewareHeaders/jasmine-browser.js)
  for details.


## New features

* --list-not-applicable CLI flag †


## Supported environments

This version has been tested in the following environments.

| Environment       | Supported versions |
|-------------------|--------------------|
| Node              | 20**, 22, 24, 26   |
| Safari**          | 26.4               |
| Chrome            | 150*               |
| Firefox           | 140, 153*          |
| Edge              | 151*               |

\* Evergreen browser. Each version of Jasmine is tested against the latest
version available at release time.<br>
\** Supported on a best-effort basis. Support for these versions may be dropped
if it becomes impractical, and bugs affecting only these versions may not be
treated as release blockers.
